# 数据与部署边界

这是单用户本地工具，默认仅监听 127.0.0.1。它会按用户提供的路径读取参考录音、课件和显式引用的资源，不应直接暴露到公网。

- Codex 登录信息由官方 CLI 管理，项目不复制或读取凭证文件。
- 外部 API Key 只保留在服务内存，不写入任务 JSON 或浏览器 localStorage。重启后需再次输入，或使用环境变量。
- 公开产物接口采用文件白名单，不提供 request.json、参考录音、模型原始输出或任意磁盘文件。
- 阻止跨站 POST 和非本机 Host。参考网页拒绝私有网络地址，限制重定向、类型和下载大小。代理 DNS 若返回 198.18.0.0/15 虚拟地址，会通过 Google HTTPS DNS 验证域名的公开地址；私有地址和直接填写的保留 IP 仍被拒绝。域名解析检查不应当作公网多租户服务的完整 SSRF 防护；公网部署还需要网络隔离和身份鉴别。
- 用户提供的 HTML 可能包含 JavaScript。只选择信任的课件；预览 iframe 使用沙箱，渲染使用临时 Chrome profile。不要把本工具当成恶意 HTML 的隔离分析环境。
- 任务目录可能包含用户资料和声音，已加入忽略规则。源码打包脚本只复制 Git 跟踪且在公共目录白名单中的文件，不收集未跟踪临时文件。`scripts/audit_release.py --history` 检查当前文件及历史中的高置信度凭证模式、个人主目录路径和私有文件。此检查不保证发现所有敏感数据，发布者仍需审阅实际 diff。
- 模型输出只能成为经校验的 JSON、HTML 和文案，不作为 shell 命令执行。外部引用材料明确作为不可信数据传入提示词。

使用本人或有授权的参考声音，遵守模板、字体、模型权重和资料的许可。内容的自动检查不替代发布者的事实核验。
